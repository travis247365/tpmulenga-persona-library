Measured Modelled Assumed

Every figure carries one, or the source line under the block does. A modelled number is never presented as measured. This is the single rule in the system that overrides visual preference — if the chip crowds the layout, change the layout.

Rules

  • Four tiles maximum per row. Five means the row is doing a table's job.
  • Value 44px Bold tabular · label 13px Medium uppercase +.06em. Label sits under the value, never above.
  • Separators are 1px hairlines, not card borders. A KPI row is one object.
  • Round to the precision the decision needs — ZMW 128.9m on a slide, the exact kwacha in the appendix.
  • Deltas name the comparison (“vs June”), never a bare percentage.
  • Green/red deltas are the only non-brand colours in the system, and only on deltas. They are darkened on white (#1E7A46 / #B00020) and lightened on charcoal so both pass AA.
