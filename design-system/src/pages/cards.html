Rules

  • Padding 24; 32 when the card holds a heading and more than three lines.
  • Square corners, no shadow. Depth comes from tone (white → surface → blue-gray → charcoal-soft), never from elevation.
  • One accent-rule card per section. If everything is emphasised, nothing is.
  • Cards in a row are equal height. Let the shortest set the height and pad the rest — do not let content set it.
  • A card never carries both an accent block and a step number. Pick the one that matches the section.
